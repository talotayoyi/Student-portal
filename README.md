# Student Information Portal

A simple web app for registering and viewing student information.

## Files

- index.html - Page structure and registration form
- style.css - Styling and layout
- script.js - Student data and form logic

## How to Run

1. Put all three files in the same folder.
2. Open index.html in your browser.

## Features

- Shows a table of students
- Form to add new students
- Stops duplicate registration numbers
- Shows success or error messages
- Works on mobile and desktop

## How It Works

1. script.js stores student data in a list.
2. The table is created from that list when the page loads.
3. When the form is submitted, it checks if the registration number already exists.
4. If it exists, an error message is shown.
5. If not, the student is added and the table updates.
